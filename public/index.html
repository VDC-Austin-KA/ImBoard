    Cue language — learn it once, keep eyes on the road

    • 2 pulses (left ear) = turn LEFT · 3 pulses (right ear) = turn RIGHT
    • Short pulses = bear / keep · Long pulses = sharp turn · 4 = U-turn
    • 1 long + N short = roundabout, take exit N
    • Soft single chime ≈ 12 s before · pattern ≈ 5 s before · long buzz = turn NOW
    • Rapid ticks = steep section ahead, check speed · Low drone = off route

    This browser has no vibration support (e.g. iPhone Safari). Chimes work through headphones or speaker — stereo panning tells left from right.

    Map layers (layers button, top right)

    • Elevation shading: blue = lowest ground in view → red = highest. Contours label elevation; ▲/▼ mark hilltops & low points (tap ▲ to start a run there).
    • Pavement condition (Austin): green A/B smooth → red D/F rough. Fresh asphalt: bright cyan = new overlay in the last year; brown dots = fresh chip seal (rough).
    • Planned resurfacing: dashed purple = overlay scheduled this fiscal year. Road construction: dashed red, from OpenStreetMap.

    Ride responsibly: wear a helmet, obey traffic laws, and check routes yourself — map and elevation data can be wrong.
